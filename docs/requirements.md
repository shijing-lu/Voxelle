# 需求文档：本地视频转文字

## 目标

为 Windows 用户提供可处理本地视频的桌面应用。用户可选择一个视频、多个视频或文件夹，检查音轨，选定语音识别模型，获得原文转写和带时间轴的字幕。项目不提供翻译、说话人识别或目录监控。

## 用户流程

1. 在设置中填入 Groq、OpenAI 或兼容服务的 API Key，并选择模型。首次使用云端识别时明确显示将上传提取后的音频及所选服务商。
2. 导入文件或文件夹。文件夹默认只导入当前目录，可选递归导入。支持 MP4、MOV、MKV、WebM、AVI、M4V 和常见音频文件。
3. 对多音轨媒体查看音轨索引、语言和名称，选择要转写的音轨。默认第一条音轨。
4. 开始队列。可查看每个文件的状态、错误、模型、已完成片段和输出路径，可取消单个任务。关闭应用后未完成任务可以续跑。
5. 每个任务输出与源文件同目录、同基名的 TXT、SRT 和 VTT。同名文件存在时由用户选择覆盖、自动另存或跳过。TXT 是原始识别稿，字幕内容来自带时间戳的原始分段。
6. 可选使用 Pi AI 订阅模型对原始识别稿做标点、分段和格式整理，另存 `.formatted.txt`；此步骤默认关闭，不替换原稿和字幕。

## 功能需求

| 编号 | 要求 | 验收要点 |
| --- | --- | --- |
| R1 | 单文件、多文件、文件夹导入 | 忽略不支持格式和重复路径，告知原因 |
| R2 | 音轨检查与选择 | 至少显示索引、语言和名称；无音轨时清楚报错 |
| R3 | 云端 ASR 配置 | 预置 Groq Turbo、Groq Large V3、OpenAI Whisper-1；允许自定义 OpenAI 兼容转写端点 |
| R4 | 中英及多语言原文识别 | 语言默认自动检测，也可指定 ISO 语言代码；不自动翻译 |
| R5 | 长音频处理 | 本地抽取音频并分片，仅上传音频片段；拼接绝对时间戳 |
| R6 | 批量执行 | 队列状态落盘；429、5xx、临时网络失败退避重试；取消不会生成不完整成品 |
| R7 | 结果导出 | 纯文本、SRT、VTT；空音频、无分段时间戳时给出明确错误 |
| R8 | 凭据配置 | Windows 系统加密保存 Key/OAuth；界面不回显密钥；支持删除配置 |
| R9 | Pi AI 可选处理 | Anthropic、OpenAI Codex、GitHub Copilot OAuth；仅上传识别文本；原稿保留 |
| R10 | 输出冲突 | 覆盖、另存、跳过三选一；同一媒体的三个输出文件采用一致的基名 |

## 非功能需求

- 媒体原文件不被修改，临时音频在任务结束或取消后清理。断电遗留文件在下次启动时清理。
- 外部 API 请求只允许 HTTPS；自定义端点需明确提示用户其音频将发送到该地址。
- API Key 与 OAuth 凭据不得写入日志、任务文件、错误提示或渲染进程持久状态。
- 所有网络调用、FFmpeg 进程和批量任务均可取消。界面不能因长视频或网络等待失去响应。
- 中文界面。安装后无需用户另外配置 FFmpeg。

## 边界与验收

首发目标是 Windows 桌面应用及安装包。模型费用由用户的服务商账户承担，界面展示估算仅作参考。公开模型指标不能代替项目实测；采用公开许可样本和用户授权的匿名样本对比中文 CER、英文 WER、中英混说、耗时与成本。
