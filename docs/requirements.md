# 需求文档：本地视频转文字

## 目标

为 Windows 用户提供可处理本地视频的桌面应用。用户可选择一个视频、多个视频或文件夹，检查音轨，选定语音识别模型，获得原文转写和带时间轴的字幕。项目不提供翻译、说话人识别或目录监控。

## 用户流程

1. 在设置中填入 Groq、OpenAI 或兼容服务的 API Key，并选择模型。首次使用云端识别时明确显示将上传提取后的音频及所选服务商。
2. 导入文件或文件夹。文件夹默认只导入当前目录，可选递归导入。支持 MP4、MOV、MKV、WebM、AVI、M4V 和常见音频文件。
3. 对多音轨媒体查看音轨索引、语言和名称，选择要转写的音轨。默认第一条音轨。
4. 每次提交本地文件或公开视频链接时勾选输出格式，可选 TXT、SRT、VTT 的任意非空组合，默认只选 TXT。同一批次的任务使用同一选择。
5. 开始队列。每个任务显示阶段和大概进度，批次显示汇总进度；可查看错误、模型、已完成片段和输出路径，可取消单个任务。关闭应用后未完成任务可以续跑。
6. 本地任务输出到源文件目录，链接任务输出到设置的统一目录。只生成选定且有足够数据支持的格式；同名文件存在时由用户选择覆盖、另存或跳过。TXT 是原始识别稿，字幕内容来自带时间戳的原始分段。
7. 完成且生成 TXT 的任务可在应用内预览、选择部分文本复制或一键复制全文。
8. 可选使用 Pi AI 订阅模型对原始识别稿做标点、分段和格式整理，另存 `.formatted.txt`；此步骤默认关闭，不替换原稿和字幕，需先生成 TXT。

## 功能需求

| 编号 | 要求 | 验收要点 |
| --- | --- | --- |
| R1 | 单文件、多文件、文件夹导入 | 忽略不支持格式和重复路径，告知原因 |
| R2 | 音轨检查与选择 | 至少显示索引、语言和名称；无音轨时清楚报错 |
| R3 | 云端 ASR 配置 | 预置 Groq Turbo、Groq Large V3、OpenAI Whisper-1；允许自定义 OpenAI 兼容转写端点 |
| R4 | 中英及多语言原文识别 | 语言默认自动检测，也可指定 ISO 语言代码；不自动翻译 |
| R5 | 长音频处理 | 本地抽取音频并分片，仅上传音频片段；拼接绝对时间戳 |
| R6 | 批量执行 | 队列状态落盘；429、5xx、临时网络失败退避重试；取消不会生成不完整成品 |
| R7 | 结果导出 | 纯文本、SRT、VTT；空音频、无分段时间戳时给出明确错误 |
| R8 | 凭据配置 | Windows 系统加密保存 Key/OAuth；界面不回显密钥；支持删除配置 |
| R9 | Pi AI 可选处理 | Anthropic、OpenAI Codex、GitHub Copilot OAuth；仅上传识别文本；原稿保留 |
| R10 | 输出冲突 | 覆盖、另存、跳过三选一；仅检查本任务实际选定且能生成的格式，所生成文件采用一致的基名 |

## 非功能需求

- 媒体原文件不被修改，临时音频在任务结束或取消后清理。断电遗留文件在下次启动时清理。
- 外部 API 请求只允许 HTTPS；自定义端点需明确提示用户其音频将发送到该地址。
- API Key 与 OAuth 凭据不得写入日志、任务文件、错误提示或渲染进程持久状态。
- 所有网络调用、FFmpeg 进程和批量任务均可取消。界面不能因长视频或网络等待失去响应。
- 中文界面。安装后无需用户另外配置 FFmpeg。

## 边界与验收

首发目标是 Windows 桌面应用及安装包。模型费用由用户的服务商账户承担，界面展示估算仅作参考。公开模型指标不能代替项目实测；采用公开许可样本和用户授权的匿名样本对比中文 CER、英文 WER、中英混说、耗时与成本。

## 公开视频链接扩展需求

| 编号 | 要求 | 验收要点 |
| --- | --- | --- |
| R11 | 单视频公开链接 | 支持 YouTube、哔哩哔哩标准链接及短链接，一次粘贴多个；拒绝其他域名与播放列表，重复链接仅入队一次 |
| R12 | 字幕优先 | 人工字幕优先于自动字幕；带时间轴时按选择导出，只有纯文本时最多导出 TXT |
| R13 | 无字幕回退 | 只下载音频轨到临时目录并调用当前 ASR；缺少 Key 时说明原因；任务结束清理临时媒体 |
| R14 | 统一输出 | 链接结果写入用户配置目录，以平台、视频 ID、清理后的标题命名；任务显示提取方式及实际服务商 |
| R15 | Deepgram | 专用 `nova-3` 适配器使用 `Token` 认证和 utterances 时间戳，不能当成 OpenAI 兼容端点 |

首版只处理无需登录即可访问的公开单视频；不处理播放列表、分P、直播、私密、会员、付费、年龄限制或 DRM 内容，不使用账号 Cookie。平台字幕和音频提取依赖非官方 `yt-dlp`，平台规则、地区网络和接口变动可能导致失败；失败时提示改用本地文件导入。有字幕时无需 ASR 费用；无字幕时费用由所选服务商计收。YouTube 官方字幕下载接口要求视频编辑权限，公开链接提取应由使用者遵守平台条款及适用法律。

## 进度、可选格式与复制扩展

| 编号 | 要求 | 验收要点 |
| --- | --- | --- |
| R16 | 任务及批次进度 | 每任务显示阶段、已知切片进度和大概百分比；未知时显示等待状态；每次导入形成可见批次汇总，终态任务计入“已处理” |
| R17 | 格式选择 | 每次导入默认 TXT，可任选一种、两种或三种，至少一种；所选格式随任务保存，重试和重启保持一致 |
| R18 | 纯文本字幕限制 | 未选 TXT 且无时间轴时不生成文件，提示选择 TXT 后重试，不自动调用 ASR；选了 TXT 时完成 TXT 并提示无法生成选定的 SRT/VTT |
| R19 | TXT 应用内复制 | 只为已完成且有 TXT 的任务提供预览，支持选中文本的常规复制和一键复制全文；不修改原始稿 |

旧任务缺少格式字段时继续按 TXT/SRT/VTT 三种格式处理。失败、取消和跳过的任务计入批次“已处理”进度，但单任务保留原有状态和错误信息。进度属于估算值，平台探测与下载期间可能没有可计算的百分比。
# 配置与界面补充要求（2026-09-30）

- 语音转写支持保存多套命名配置，每套保存服务商、模型、语言、自定义端点和独立加密的 API Key；可快速切换当前配置，新任务使用当前配置，已入队任务沿用创建时的配置。
- 升级时保留原设置、凭据和任务。软件名称为 Voxelle；左侧导航保持固定，右侧任务和设置内容独立滚动。
